When making architectural changes (new systems, modified signal flows, camera changes, scene hierarchy modifications, or system responsibility changes), update /ARCHITECTURE.md with:
1. Add new systems to the "Key Systems" section with purpose, location, responsibilities, and API
2. Update "System Diagrams" if communication patterns change
3. Update "Data Flow" for new signal flows or event chains
4. Add to "Recent Architectural Changes" with date, issue, changes made, and impact
5. Update "Scene Hierarchy" if node structure changes
6. Update relevant subsections for specific systems (e.g., Camera System section)

Keep entries concise but informative. Use code blocks for technical examples.
